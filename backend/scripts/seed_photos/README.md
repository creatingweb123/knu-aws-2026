## 앱에서 첨부하기

1. 데모 실행자 계정으로 계획을 이어받거나 진행 중인 계획을 열고 경험 기록 화면으로 이동합니다. 시드에서 이미 완료된 계획의 사진으로 시연하려면 같은 주제로 새 계획을 만들어 이어받습니다.
2. **다녀온 이야기**를 작성하고 **사진 (선택, 1장)**에서 위 표의 JPEG를 고릅니다.
3. 미리보기를 확인하고 **사진과 경험 기록 보내기**를 누릅니다. 전송이 끝나면 계획자 계정의 수신함에서 사진을 확인할 수 있습니다.
