# 이어온 하루 — 취소된 하루를 양도합니다

AWS Skill Training 1조 프로젝트 저장소입니다. 기획·명세 문서와 백엔드·프론트엔드 코드를 모두 이 저장소에서 관리합니다.

**이어온 하루**는 사정이 생겨 하지 못하게 된 하루(계획)를 다른 사람에게 넘기고, 그 사람이 다녀온 기록을 돌려받는 모바일 웹입니다. 계획을 남기는 사람을 **계획자**, 이어받아 실행하는 사람을 **실행자**라고 부릅니다.

```
[계획자] 취소된 하루를 남긴다 → [실행자] 한 명이 이어받는다 → 다녀온 기록을 보낸다 → [계획자] 수신함에서 읽고 답장한다
```

MVP는 이 흐름을 검증하기 위해 한 동네의 공개 장소 1–3곳을 방문하는 짧은 계획(산책·나들이)만 받습니다. 서비스의 중심은 계획의 종류가 아니라 아래 세 가지입니다.

## 핵심

| 핵심 | 내용 |
|---|---|
| 양도와 반환 | 취소된 계획과 그 계획에 담긴 사연(왜 이 계획을 세웠는지)을 공개하고, 한 명이 이어받고, 실행자가 직접 경험한 기록(글 + 선택 사진 1장)이 원래 계획자에게 돌아간다 |
| 정합성 | 여러 사람이 동시에 요청해도 **한 명만 확정**한다. 같은 완료 요청을 재시도해도 방문 기록과 수신함 알림은 **한 건**이다. 포기한 뒤 들어온 이전 요청은 거부한다 (DynamoDB 조건부 갱신·트랜잭션, 보장 G1–G4, 검증 시나리오 T3–T7) |
| AI 정리 | 계획자가 적은 사연을 세션형 에이전트가 활동 목록, 계획 이유, 방문 질문 한 개로 정리한다. 원문에 없는 내용은 에이전트가 검사 도구로 점검해 고치고, 꼭 필요한 빈칸만 최대 2번 묻는다. 사용자가 확인한 카드만 저장한다 |

## 사용자와 흐름

| 역할 | 설명 |
|---|---|
| 계획자 | 이사나 일정 변경으로 계획했던 하루를 하지 못한 사람 |
| 실행자 | 남이 남긴 계획을 이어받아 직접 해보고 싶은 사람 |

1. 계획자가 사연을 입력하면 AI가 하루 카드로 정리하고, 계획자가 폼에서 다듬어 공개합니다. AI가 실패하면 직접 작성으로 넘어갑니다.
2. 실행자가 둘러보기에서 하루를 읽고 이어받습니다. 확정되는 사람은 한 명이며, 포기하면 다시 공개됩니다. 기한은 이어받은 뒤 3일입니다.
3. 실행자가 방문 기록(글 + 선택 사진 1장)을 보냅니다. 사진은 비동기로 처리하면서 위치 정보를 지우고, 처리에 실패하면 글만으로 완료할 수 있습니다.
4. 계획자가 수신함에서 원래 계획과 방문 기록을 나란히 읽고 한 줄 답장을 보냅니다.

동네 문화공간을 초기 도입 후보로 검토합니다. 운영자용 기능은 MVP에 넣지 않습니다.

## 구성

React 모바일 웹과 AWS 서버리스 API로 이루어집니다. 구성도는 [§2.1](./docs/02-architecture.md)에 있습니다.

| 영역 | 기술 |
|---|---|
| 프론트엔드 | React 18, TypeScript, Vite, React Router, TanStack Query, Amplify Auth, MSW(개발용 목업) |
| 백엔드 | API Gateway(HTTP API) + Lambda(Python 3.12), DynamoDB 단일 테이블, Cognito, S3 + SQS(사진 처리) |
| AI | LangGraph `StateGraph` 에이전트가 외부 OpenAI 호환 LLM API를 호출. 공급자는 설정으로 교체하고, 문제가 있으면 `AGENT_MODE=pipeline`(레벨 0)으로 낮춘다 |
| 개발 환경 | docker compose(AWS 호환 에뮬레이터, HTTP 어댑터, Fake LLM). 개발과 단위·로컬 통합 테스트용 |
| 배포·검증 | AWS SAM, CloudFront + S3, CloudWatch. 데모와 T1–T22 검증은 실제 AWS 스택에서 한다 |

## 문서 사이의 우선순위

- 요구사항 목록(6장)과 명세(2–5장)가 다르면 명세가 우선합니다.
