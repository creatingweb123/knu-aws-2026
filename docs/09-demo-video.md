## 3. 장면별 구성

자막은 사용자 입장의 짧은 문장으로 쓴다.

### 장면 1. 도입 (0:00–0:10)

- 타이틀 **이어온 하루** 위로 지연의 둘러보기 화면. 카드 목록을 천천히 스크롤한다(산책, 전시회, 책방, 공원 등 다양한 하루).
- 자막: "사정이 생겨 못 한 하루, 다른 누군가가 대신 다녀와 줄 수 있다면?"

### 장면 2. 취소된 하루 남기기 (0:10–0:45)

| 시간 | 화면 | 동작 |
|---|---|---|
| 0:10 | 둘러보기 → 사연 입력 | "취소된 하루 남기기" → 사연 붙여 넣기 |
| 0:17 | AI와 함께 정리하기 | 버튼을 누르면 정리 단계가 차례로 켜짐(대기 시간은 컷 편집) |
| 0:24 | 질문 말풍선 | "산책은 대략 얼마나 걸릴 예정이었나요?" → **[45분]** |
| 0:30 | 카드 미리보기 | 제목·장소 2곳·방문 질문이 채워진 카드, "AI가 바꾼 것" 메모 |
| 0:37 | 폼 → 공개 완료 | "폼에서 다듬기" → 스크롤로 훑고 "이 하루 공개하기" |

사연:

> 이사 가기 전에 출근길에 늘 지나치던 빵집에서 소금빵을 사고, 하천 산책로 벤치에 앉아 동네를 한 번 더 보고 싶었어요. 그런데 이삿짐 정리가 길어져서 결국 못 갔어요.

- 자막: "못 하게 된 사연을 적으면 AI가 하루 카드로 정리해 줘요." → "필요한 것만 한 번 물어봐요." → "확인하고 공개하면 끝."

### 장면 3. 둘러보고 이어받기 (0:45–1:10)

화면을 좌우로 나눠 수현(왼쪽)·민준(오른쪽)을 함께 보여 준다.

| 시간 | 화면 | 동작 |
|---|---|---|
| 0:45 | 둘러보기 | 두 사람 모두 맨 위의 지연 하루를 봄 |
| 0:50 | 하루 들여다보기 | 취소한 이유, 방문할 장소와 하고 싶었던 일 |
| 0:58 | 이어받기 | 두 사람이 거의 동시에 "이 하루 이어받기" |
| 1:00 | 결과 | 수현: 내 하루로 이동(기한 "D-3"), 민준: "이미 다른 사람이 이어받았어요" |

- 자막: "마음에 드는 하루를 골라 이어받아요." → "하루는 한 사람에게만 이어져요. 기한은 3일."

### 장면 4. 다녀온 이야기 보내기 (1:10–1:35)

| 시간 | 화면 | 동작 |
|---|---|---|
| 1:10 | 자막 카드 | "— 다음 날 —" |
| 1:12 | 내 하루 | 기한과 진행 단계 → "다녀온 이야기 쓰기" |
| 1:15 | 그날의 이야기 | "지연에게" 라벨과 방문 질문 → 편지 입력(타이핑은 배속) → 사진 첨부 |
| 1:28 | 보내는 중 → 전송 완료 | "사진과 경험 기록 보내기" → 완료 화면 |

편지:

> 지연 님, 출근길 빵집에서 소금빵을 사서 하천 벤치에 앉아 먹었어요. 물소리랑 자전거 지나가는 소리가 들렸고, 빵은 아직 따뜻했어요. 이 동네에 막 이사 온 저에게 첫 산책 길이 생겼어요.

- 사진: `backend/scripts/seed_photos/open-1.jpg`(천변 벤치 위 종이봉투와 소금빵)
- 자막: "직접 다녀온 이야기와 사진 한 장을 계획한 사람에게 보내요."

### 장면 5. 수신함과 답장 (1:35–1:55)

| 1:35 | 헤더·하단 탭 | 편지 아이콘의 새 편지 점 |

## 4. 촬영 준비

1. **데이터 초기화**: 촬영 직전 시드를 다시 만든다. 둘러보기와 수신함이 비어 보이지 않게 하기 위해서다.
   ```bash
   cd backend && python scripts/seed.py --stack haru-demo --reset --apply --confirm-stack haru-demo
   ```
2. **중복 카드**: 시드 `open-1`이 이미 지연의 "이사 전, 마지막 동네 산책"이라 새 카드와 비슷한 카드가 둘 뜬다. 촬영용으로 `open-1`을 빼고 시드하거나(커밋하지 않음), 그대로 두고 맨 위 카드만 쓴다.
3. **AI 워밍**: 촬영 5분 전 "AI와 함께 정리하기"를 한 번 돌려 첫 응답 지연을 없앤다(공개하지 않는다). 데모 사연이 질문 1개로 끝나는지 리허설로 확인한다.
4. **브라우저**: 계정마다 창 하나(크롬 프로필 2개 + 시크릿 창 등). DevTools 기기 모드 390×844로 세로 화면 고정. 세 계정 모두 미리 로그인해 둔다.
5. **이어받기 승자**: 누가 이길지 정해져 있지 않다. 민준이 이기면 민준이 "이어받기 포기"를 해 하루를 다시 공개한 뒤 다시 찍는다.
6. **수현의 기존 이어받기**: 시드에서 수현은 "비 오는 날 시장 구경"을 이어받은 상태다. 새 하루를 이어받는 데 문제가 없는지 리허설에서 확인하고, 막히면 촬영 전에 포기한다.
7. **편집**: AI 대기, 사진 처리 대기, 편지 타이핑은 배속이나 컷으로 줄여 2분에 맞춘다.
